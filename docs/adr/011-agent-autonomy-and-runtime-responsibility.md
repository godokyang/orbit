# ADR-011：由 Agent 判断任务，Orbit 提供事实与执行支持

状态：2026-10-16 用户确认；本轮只调整文档，待实现。部分替代 [ADR-008](008-omp-native-collaboration-base.md) 的成员范围、检查取证与程序处置职责，以及 [ADR-009](009-user-selected-model-pool.md) 的交接范围约束；OMP 单宿主、原生协作、模型授权和真实停止要求保持。具体目标规则归属[任务运行合同](../../contracts/task-runtime.md#已确认的职责调整待实现)，实施状态归属[交接](../plan/handoff.md)。

Orbit 的目标是让 Agent 尽量完整、便宜、自动地完成用户任务，减少用户催促、转述和纠偏。便宜要按完成整项任务的总投入判断，包含返工、重复检查、等待和用户介入，不能只看单次模型价格或输入长度。

Zeen 与 Loom 的[体验复核](../reference/orbit-experience-review-20261015/README.md)表明，程序将部分需要理解任务才能作出的判断变成了预先限制或自动处置：成员被文件名单阻挡，检查者取不到相关记录，申诉被截短，裁定因期间变化持续作废，技术问题被转成等待用户。这些限制增加了往返与人工介入，是调整职责的理由。成员编辑另有加载旧依赖的安装回归，不能把所有编辑阻断都归因于名单。

这些材料来自同一用户的两个项目，三份使用评价为执行 Agent 自评；源码缺陷和可复核行为可据此定位，整体收益不能按独立用户实验外推。检查者漏读已有材料并误报完成是另一项已发生的问题，不能以“名单没有防住漏判”为取消名单的因果依据。

因此采用以下职责：Root 决定实现、分工、纠偏、争议处理以及是否需要用户介入；成员自行调查并选择任务所需的文件和方法；检查者与裁定者独立、只读地调查相关证据。Orbit 准确记录并传递要求、执行事实、结果和变化，执行 Agent 的决定，落实用户明确授权与停止要求。信息不足时说明缺什么、提供查证入口；程序不能把未知自动解释为失败、结果无用或必须由用户处理。

这替代了继续扩充文件白名单、场景专用验收规则和自动作废条件的方向。代价是 Agent 仍可能判断错误，读取更多材料也可能增加单次调用成本；通过完整证据、Root 事后核对和独立检查来发现与纠正，不增加自动重置系统，也不承诺取消限制就能消除漏判。

授权、实际执行身份、独立检查与真实停止仍须核实。Root 处理裁定不等于可以自行宣布独立终检通过。JEV 先补完整日志再观察，同时分析输入完整性和调用频率，不凭旧分数猜测其失误原因或同时更改阈值。EXP-07、EXP-10 暂不单独调整；EXP-11 已列为具体调查任务，沿要求、取证与最终结论核对漏判，不能以开放读取代替修复；EXP-13 活动会话路径修复于同日后续确认纳入实施，顺序见[执行计划](../plan/agent-autonomy-implementation.md)。

外部集成字段与状态继续遵守 [ADR-010](010-integration-contract.md)。本决定没有发布新接口，也没有改变现行机器合同；涉及 `needs_user` 和续接的实现须明确兼容方式后同步合同与能力声明，不能直接重解释已有终态记录。

## 2026-10-16 独立审核后的补充确认

用户确认吸收[独立审核](../reference/orbit-experience-review-20261015/independent-decision-review-20261016.md)中的实际遗漏，不恢复预列文件名单或程序代替 Agent 判断的方案：

- 编辑解析回归可独立修复，无需等职责改造全部完成；临时修复不能成为长期保留名单的理由。
- 文件名单与命令执行、网络、凭据处理、任务记录写入保护须分别核对，不能因代码绑在一起就全部删除，也不默认照搬所有旧限制。并行成员的实际修改记录供 Root 事后核对，不引入预分配文件、自动重置或额外隔离。
- 自主只读调查仍须说明数据来源、受检版本与模型外发范围，落实已有用户授权。提供更多读取能力不等于把整个历史默认发送给模型；不以此重新建立固定材料白名单。
- 取消场景验收规则后，真实命令回执和必要补查仍须可得。视觉、交互、测试各按实际要求查证，不用统一读图或逐字引用条款代替证据判断。
- 监督实际失效时的处理必须与等待用户回答区分。先核对现有监督、提问和恢复能力；不能假称仍受监督，也不把普通技术故障自动交给用户。具体失效处置仍需根据核查结果定案。

详细实施定位与调查任务统一维护在[已确认改动方案](../reference/orbit-experience-review-20261015/agreed-change-plan.md#独立审核后补充确认2026-10-16)。本轮研究建议单独标记，不自动成为产品规则。
