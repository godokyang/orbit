## 当前怎么用

- 受控会话：在项目目录运行 `orbit omp`，原生 `--resume`、`--model`、profile 与权限参数原样交给 OMP。Root 用原生 `task` 派发成员，Orbit 负责登记、观察、检查与停止确认。
- 查询与维护：`orbit status` / `orbit stop` / `orbit doctor`；`orbit update` / `orbit uninstall` 只管理本安装。检查模型取当前 OMP 会话的 provider/id，或显式 `ORBIT_REVIEW_MODEL`。
- 模型候选池（ADR-009，已实现并验收）：会话内 `/orbit-models` 增删跨会话候选池；检查者失败后用 `orbit review-model TASK --model provider/id` 显式重选（同一任务内已有真实样本，含失败→重选→任务 `complete`+停止）。成员模型漂移检测／中止+双层停止确认也已有真实样本（最终构建 `6f808e8d…`，早期失败保留为回归历史）；池内自动（非显式）正选择为 live 边界（确定性测试覆盖，live 尝试被质量线正确拒绝）。见[验收证据](../reference/model-pool-acceptance-20260925.md)。
- 安装位置（默认）：runtime `~/.local/share/orbit/orbit`，CLI `~/.local/bin/orbit`；本机当前已有该安装（0.7.3，release `cbf09632343fc0ed2a305d8b`，source commit `2157f28b…`（安装时 clean），`content_digest 7b9fccf2…`，`installed_at 2026-09-25T17:37:00Z`）。更新在任务结束后进行；仍有存活 lease 时卸载会拒绝并保留完整安装。
