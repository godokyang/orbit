## 目标与验收

- 用户全局启用后，所有 Orbit 任务都使用 Jev 对近期执行和有限产物信息作窄判断；单项目可关闭。
- Jev 只决定何时唤起现有独立检查者。卡住／偏题疑点进入过程检查，产物就绪进入完整检查；Jev 本身不纠错、不裁定完成、不停止 Root。
- 保留用户请求、约定时间和 Root 交付触发的完整检查。相同观察不反复唤起检查；Jev 缺 key、超时或服务失败时沿用原检查路径。
- 限制发送的任务文字、会话观察和代码差异；记录模型版本、判断和可得用量，不保存 key 或外发正文。
- 相关既有测试、必要的新回归，以及真实 Jev 和 Orbit 流程由开发侧完成；真实凭据缺失须如实标注，不能把夹具称作真实验收。
