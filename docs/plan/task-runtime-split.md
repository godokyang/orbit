## 1. 目标

`contracts/task-runtime.md` 现在同时写产品不变量与 OMP 适配细节。拆分后：

- `contracts/task-runtime.md`：与宿主无关的产品不变量；
- `contracts/host-omp.md`：OMP 专属的入口、钩子、socket、注入形状、进程组与版本行为。

每条规则只出现一次；不改变任何语义；逐节审阅差异。
