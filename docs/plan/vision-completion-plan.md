# Orbit 当前计划

## 目标与依据

高质量完成用户需求，能发现并纠正偏差，减少人工介入，并根据实际结果优化供应商消耗。Orbit 独立用于任何项目，Feedback 通过同一入口接入。当前决定由 [ADR-007](../adr/007-task-runtime-refactor.md) 和 [任务运行合同](../../contracts/task-runtime.md) 维护。

## 已完成的范围

2026-09-14 已完成独立任务进程、原文和指定依据留存、实际内容快照、约定时间检查、向已有 Root 投递纠正、按需独立裁定、原生停止确认，以及 CLI、skill、角色规则和模型配置说明。旧运行架构已直接删除，无兼容层。

冻结的两条真实验收均通过：遗漏被独立发现并由原 Root 修正；明确截止后实际停止相关执行且上下文保留。确定性测试另外验证版本失效、误报裁定、等待不唤醒模型和停止未确认。完整事实与时间／用量复盘见 [验收记录](../reference/orbit-runtime-acceptance-20260914.md)。

文档清理已完成：现行设计、使用入口、开发规范和验收事实保留；旧阶段和重复材料退出当前目录。后续不重新执行旧阶段，也不为证明这次文档清理重跑模型实验。

## 下一步优先项

将新版用于用户日常已有会话。先核对实际命令入口与原生控制通道，再决定必要的配置或适配；当前环境事实见 [交接](handoff.md)，能力边界见 [当前限制](debt-ledger.md)。这一步尚未完成，本轮文档清理未启动运行环境改造。

已有两条实验不自动扩展为完整供应商矩阵。选择新的真实使用任务时，按其目标约定最小验收，观察交付质量、人工纠偏与实际检查成本；不能把小实验的通过当成已证明普遍节约额度。

不建设需求讨论管理、Root 自动替换／恢复、无实际调用方的兼容层或跨项目统计平台。后续实现、发布和外部项目修改按用户明确授权执行。
