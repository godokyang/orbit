# Orbit 当前限制

最后核对：2026-09-30（installed 0.7.26、pair4 两臂终态后）。这里只保留**当前仍受影响**的缺口；已由后续版本解除的限制按历史快照在 reference/Git 留存，不在这里重开已结束票。认可方案的逐项改造维护在[代码审计](mixed-model-delivery-code-audit.md)，不在这里另建队列。现行行为见[合同](../../contracts/task-runtime.md)及 ADR-008/009。已结束 M4 的冻结判定和例外见[历史验收](../reference/omp-native-m4-acceptance-20260924.md)。
| 限制 | 当前影响 | 解除条件 |
| --- | --- | --- |
| park/dispose 后退出不可证实 | 默认 `task.agentIdleTtlMs=0` 保持 session attached 的已完成成员可核对；用户覆盖或异常 park 后失去 session，不能把 idle、cancel 回执当退出，保留 `stop_unconfirmed` | 上游提供 dispose 完成信号并验证对应真实路径 |
| 异常退出时协作日志仍可能缺失 | 可归属事件已另写 `collaboration.jsonl`，但异步写入未完成、写入失败和旧任务仍可能不完整；导出必须显示缺口 | 可恢复事件流或同步确认边界，并完成真实异常退出验证 |
| 上游 provider 与控制钩子有缺口 | `devin-agent` 类不触发 `before_provider_request`；部分异常不能可靠 fail-close。单成员编程 kill、已 park 工作和保留名称碰撞也受上游接口限制 | 实证确认所缺的最小接口，按 ADR-008 跟进，不预维护 Fork |
| 自动入口失败时未知请求体 | 已核对的 OMP messages / Responses 可传恢复提示；不能安全识别的请求体仍中止，不能声称普通执行已可恢复 | 取得实际请求体与返回契约并完成隔离验证 |
| 历史读取有前置条件 | 需要已加载且具备历史读取能力的持久会话；ephemeral 或未物化会话不支持 | 原生接口具备能力且有明确需求后再适配 |
| 新入口与质量判断的有限放行：收益与新构建未证 | 有限放行已随多轮实机留证（entry 判定、stage 判定、checker 选择真实调用）；**pair4（0.7.25）已证其构建上的真实派发交付闭环**。残余限定：**资源收益未证**（对照一轮为负）；**0.7.26 新变更（Go 映射/类型 help）未 live 验证**；适用域外泛化未证 | 收益按 §11.3 调整后再对照；0.7.26 变更随下次真实任务自然覆盖；域外仍为事实展示及 Root 判断，不迁旧分数 |
| 受控串行交接链的历史失败与残余 | 历史失败（phone/pair2 `members=0`、pair3 首派 429＋same-unit 重派被挡＝Seam A/B 两断点）不改判、reference 原样留存；**修复后另有正向样本：pair4（0.7.25）已证真实机械链**——同代 v2 hint→native K3 派发→注册先于模型工作→accepted→Root 集成→manual final 只读（coverage 5/0）→complete＋confirmed stop（17:02:54Z）。残余：**Seam B 失败自动释放无 live 样本**（pair4 首派成功未触发，不人为制造）；**同 unit 多次失败重派累积行为无实测**；收益对照一轮为负（旗舰 totalTokens +134.665% 分类描述、质量无可检出差异，不宣称节省） | B 依真实 provider 失败自然触发后按原件验收；负收益路径调整按主方案 §11.3 由 Root 决策 |
| 整次任务费用与用量归属可能未知 | session-summary 可汇总可得记录；失败检查 usage、Root/成员归属、实际路由价格和订阅消耗仍可能未知。交叉输入/输出单价不能直接判总成本。第一方价格／计划事实已按其适用条件留证（/private/tmp/orbit-route-facts-verify），但**现金金额与实际扣减桶**仍未核实（`cash []`／`cost_complete=false` 只表示未知，不是 0 成本），且**账户／OAuth 归属是否可得按各任务原件报告范围**区分，不得概括成“全部原生账户缺失”；两者与基准测量日期是否已知无关，也不合并成同一个 unknown。**精确归属口径待 Root 复核原件后确认**（本清单不新增结论、不重算资源） | 可核验本路由价格/额度规则及同任务归属；未知保持未知，不新增硬预算门，不用 OpenRouter 报价代替 |
| 独立检查投入仍高且净收益有限 | 历史样本有数万至数十万 input token；0.7.17 logstat 同质两臂在冻结 8 项与 6 项探针上均通过，但混合臂旗舰逐类用量更高（input/output/cacheRead 23782/4971/458112 对 23060/4904/150528）且未派发成员，**经济收益尚未证明** | 同条件比较整体交付、返工、核验和人工投入；压缩同时核对缺陷发现率与 stale 行为 |
| 真实验证尚未覆盖所有分支 | 同版本 repeat/reopen 只有确定性回归；部分矛盾夹具只证明裁定机械/只读回路。旧授权例外已撤销，不再列为当前验收条件 | 保留各报告未测边界，有真实业务需求再验证相应现行路径，不重复已结束迁移 |
| 工作区冲突不自动暂停检查 | 程序不会检测 Root 声明产物位置与绑定是否冲突，也不据此暂停 | 单独明确检测与暂停语义并取得真实路径证据 |
| 语义同义 finding 不自动合并 | 依赖检查者复用已有 id，不靠程序猜测不同 id 语义相同 | 有实际重复误报证据后再决定显式对照方案 |
| OpenRouter 覆盖与路由核验仍不完整 | 已审计声明的身份按声明条件命中；**0.7.26 后 shipped 6 条均被 loader 接受（Go subscription 修复，实测 6/6、installed release 同）**，但**GLM、Go V4 等池身份尚未映射**，测量日期/方法多数 unknown，且映射命中不是费用或专属 route 质量证明（限定理由存 mapping-audit）。消费者边界：**pair4（0.7.25）已证 task-fit 消费真实发生**；0.7.26 的 6/6 仅 loader 级证明、无新增模型调用 | 补充第一方来源映射并核实测量日期；无需全型号认证门 |
| 有池成员默认门与检查者兜底：新方向收益与 0.7.26 变更未 live | 历史池外默认失败与 fallback 成功各有样本；pair4（0.7.25）已证池内 K3 派发→交付→终检→停止全链。残余限定：**收益方向未证**（一轮为负）；**0.7.26 新变更未 live**；多型号优选与真实费用闭合未证 | 真实可用配置中按新题义继续验证派发/身份/交付/成本；失败保留，不由别的夹具倒推 |
| 检查者历史证据可见性缺口 | rebind `35f925ba` 中检查者看不到 `checks/2` 与首改原件（只有有界 `recent_events`），导致同一 finding 多轮争议并迫使 Root 自造 `target/orbit-precheck-evidence.json`；5 次 arbiter 调用被消耗。该 bug 真实存在，不因闭环最终完成而否认 | 最小修复已随 **0.7.20** 装入（Q 静态审 PASS，回放为控制器确定性重放）；自选成员 `work_unit_id` 接缝经 Q 独立复核 PASS。**该可见性缺口本身未在本轮实机复验** |
| 既有池路由成本事实无法落盘 | **安装的 0.7.20 已实测**（隔离 CLI：`import` exit 0 存档显式未知生效日、缺标记仍 exit 1、`list` 显示 `effective.unknown=true`、两份真实台账副本 `report` exit 0 且 `cash []`／`cost_complete=false`）。显式 `"effective": {"from": null, "until": null, "unknown": true}` 可存档与列出，但该事实**不覆盖任何调用、不定价、不参与自动排序**；schema 允许价格事实落盘，当前抓取资料缺**发布生效日**（另有账户范围、已核实路由两项未闭合），不得用页面“最后更新”日期或检索时间顶替。**现金与实际扣减桶仍未知**（`cash` 空只表示未知，不是 0 成本）；**账户／OAuth 归属可得性以各自原件报告范围为准**，不外推为全部账户缺失，精确归属待 Root 复核 | 取得第一方发布生效日（并补齐账户范围与已核实路由）后可落盘定价事实；在此之前保持未知、不给金额 |
| reconcile 两臂已跑但结论有限 | installed 0.7.20 paired：冻结 8 项测试与 6 项探针**两臂各 8/8、6/6 通过**（各只跑一次），质量无可检出差异；但混合臂 **members=0**，未 exercise 成员替代路径；顶级模型 GPT-6-sol 总量 **mixed 比 baseline 约 +30%**（376410 vs 289685），用户介入两臂均为 0；自动检查 1—6 为同一 observation 上的有界失败重选 | 需在健康 provider 池与真正派发成员的任务上重复同质对照，才能谈成员替代与节省；失败与未知保留 |
