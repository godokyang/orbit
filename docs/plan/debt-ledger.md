# Orbit 当前限制

最后核对：2026-09-14。这里只保留影响当前使用的缺口；已删除架构的欠账不再构成待办。当前语义见 [ADR-007](../adr/007-task-runtime-refactor.md) 与 [任务运行合同](../../contracts/task-runtime.md)。

| 限制 | 当前影响 | 继续处理的条件 |
| --- | --- | --- |
| 日常会话接入尚未打通 | 两条真实实验使用专用 app-server；普通 embedded TUI 没有当前适配所需的外部控制端点。维护者本机入口状态见交接 | 在用户实际使用的会话环境中核实原生接入，并保持原 Root；没有端点时明确报告，不以另开 Root 代替 |
| 历史读取有前置条件 | 只接入已加载、具备历史读取能力的持久会话；ephemeral 或尚未物化的会话不可用 | 原生接口提供相应能力且有明确使用需求后再适配 |
| 停止确认范围有限 | 确认绑定 Root 当前执行、原生登记后台终端和自有检查进程；不覆盖其他供应商 Agent、脱管进程或任意外部副作用 | 对具体接入方验证观察、中断和相关资源终止，不凭单一 abort 回包扩张能力声明 |
| 整次任务费用可能未知 | 检查 tokens 可记录，Root 会话累计量可能混入先前工作，尚无跨供应商费用总计和 token 硬上限 | 有真实用量来源与任务归属后轻量补齐；不阻塞主线或从耗时推算费用 |
| 效果验证仍有限 | 已证明最小遗漏纠正与实际停止，尚未证明复杂项目普遍省额度或减少人工介入 | 在用户明确选择的真实任务中记录结果、检查成本与人工纠偏，再决定优化 |

Root 运行故障仅记录，不建设自动替换或恢复。新供应商、全局调度、需求讨论管理和复杂统计平台不因列在限制中自动获得实现授权。
