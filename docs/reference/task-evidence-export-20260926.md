# 本地任务证据与导出实施记录（2026-09-26）

本次用户确认并授权：Orbit 在项目 `.orbit/tasks/<id>/` 记录可观察的决策链，用户主动导出单任务证据包；开发者收到用户自愿交付的文件后再分析。Orbit 不自动上传、不调用模型复盘、不判定产品缺陷，也不改变现有终检或完成门。现行语义见[任务合同](../../contracts/task-runtime.md#本地任务证据与主动导出)与[ADR-008 增补](../adr/008-omp-native-collaboration-base.md)。

## 已接入源码

- OMP 插件在可归属任务的派发、实际模型、hub 与结果事件发生时追加 `collaboration.jsonl`；原文不沿用桥的 2000 字符截断，桥仍保持有界。记录写入失败、关联前事件和重启损坏的可得缺口，不让记录故障阻断原生任务。
- 运行时在 `events.jsonl` 关联检查号、模型、输入/产物版本、finding 内容、纠偏投递及复核结果。派发输入有显式理由才记录；没有理由标 `unrecorded`，Jev 建议不能冒充 Root 的派发动机。
- `orbit export TASK --output FILE` 只读生成 tar.gz：导出时任务记录、事实时间线、检查快照、可验证的原生成员会话及 Root 在任务时间窗内的会话片段、文件摘要、缺失与排除清单。运行中标注 `in_flight`；已存在的输出不覆盖，文件不会上传。

## 实际验证及边界

- `npm test` 通过，包含原生协作证据专项、运行时回归与导出回归。确定性插件场景覆盖 520 条事件后的缓冲滚动、跨任务隔离、实际模型、显式/未记录理由、写入恢复缺口与重启序号；不等于新插件已经在真实 OMP 用户任务中运行。
- `npm pack --dry-run --json` 通过，52 个文件；包含 `plugins/omp-host.mjs`、`lib/orbit/task_evidence.rb` 与任务合同。`git diff --check` 通过。
- 通过源码 CLI 对本次**运行中**任务实际执行 `orbit export`，成功生成约 6 MB 的 tar.gz（1132 条文件清单项，`in_flight=true`，3 条缺失），并读取归档中的 `manifest.json` 与 `timeline.jsonl`。该任务会话加载的是本次改动前的安装版扩展，旧协作日志缺失按清单标注；不声称新插件已完成真实宿主验收。
- 原生 Root 会话只按任务时间窗口截取，不能证明窗口内每条对话都源于 Orbit 决策；成员会话须核实原生会话头 ID。进程异常退出前未完成的异步写入可能无法恢复，旧任务亦无新记录；缺口必须按清单解读。安装版 `orbit --version` 同为 0.7.5，但本次工作区源码尚未重新安装。
