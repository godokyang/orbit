## 证据边界

放行只绑定当前问题内容／版本、输入和决策、typesafe／jev-1.13.0，以及可观察的 bounded_git_delivery_v1 单元／产物范围。样本有限，checker 正例余量薄；不证明其他领域泛化、所有候选可靠、未来缺陷发现率或经济收益。无放行、范围失配、服务失败、真实型号漂移或明确要求不满足时，仍保留事实、未知和 Root 自主选择。

这批数据没有证明 Herdr 启动的新安装 Orbit 能自主派发、集成、纠偏、完成终检和确认实际停止；也没有证明混合执行比旗舰独立执行更省资源。此两类证据需另由真实交付及同等验收比较取得。
