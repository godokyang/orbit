# 本轮原件索引

对应 [验收报告](../../local-host-snapshot-repair-acceptance-20261011.md)，保留真实失败和Controller更正；不复制源认证、隔离profile数据库或全局缓存。

- `baseline-*`：启动前既有工作与固定身份；`original-research-preservation.json`核对原未跟踪调研。
- `tested-build-v2.json` / `source-build-comparison.json` / `frozen-source-sha256.json`：受测源码、编译宿主、临时安装身份；`npm-test.log`、`package-dry-run.json`、`skill-validator.log`是工程检查原件。
- `root-*-probe/` / `adapted-permission-probe/` / `source-catalog-probe.json`：无模型实际导出、加载、副作用、生命周期、工具和图片字节；失败探针仍保留。
- `negative-evidence/` / `positive-v2-evidence/`：实际必要矩阵、推荐与原生交接、纠正和停止；各 `task.tar.gz`由官方export生成，其manifest是完整性依据。
- `storage-v3-evidence/` / `in-flight-storage-observations.jsonl`：A/repeat/C实测、独立inode、历史恢复和导出。
- `in-flight-cancel-evidence/` / `process-failure-evidence/`：实际取消/受控进程故障，失败、未知用量和停止；后者erratum保留Controller字段命名更正，未改程序原件。
- `archive-failure-evidence/`：真实归档拒绝、完整workspace留存、异常补报、旧workspace恢复与自包含export。
- `*calibration-evidence/` / `failure-v4-evidence/` / `failure-v5-evidence/`：未通过校准、既有显式选模覆盖、实际Zenmux成功，不虚构provider拒绝。
- `independent-review/`：固定H/J/K实际核查与Root对过时开发说法的纠正，开发回报不替代产品证据。
- `actual-resource-summary.json` / `actual-resource-ledgers.json`：原始类别分别统计，未知费用/订阅扣减不补零。
- `missing-omp-real/` / `pane-cleanup.json` / `fixed-resource-comparison.json` / `final-cleanup.json`：入口失败保留、真实无OMP卸载、停止后关闭pane和所属目录清理。归属不明资源保留。
- `goal-complete.json`：实际Goal工具回执，若文件不存在不能据TODO宣称Goal已完成。
