# Expense importer
Implement importExpenses(text) in src/importer.mjs. Input lines are category,amount with a required header category,amount. Strip one leading BOM, accept LF or CRLF, ignore blank lines. This is unquoted CSV; each nonblank data line must have exactly two columns. Trim both fields. Category must be nonempty. Amount must match nonnegative decimal digits with exactly two fractional digits (no sign, exponent, extra decimals). Compute integer cents exactly and reject values or per-category/overall sums outside Number.MAX_SAFE_INTEGER. Preserve first-seen category order. Return {groups:[{category,totalCents,count}],totalCents,count}. On invalid data throw Error with original one-based line number in the message, including blank lines in numbering.
CLI src/cli.mjs reads exactly one path argument as UTF-8, prints only result JSON to stdout on success (exit 0), and a concise error on stderr with empty stdout and exit 1 on argument/read/validation failures. No stack trace. README documents invocation and input/error/ordering/precision behavior. Keep tests/acceptance.mjs unchanged. No dependencies, commits, pushing or network needed. Root owns CLI/docs/integration; importer is a bounded independent module with a defined interface.
